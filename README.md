# CryptoBankPro

CryptoBankPro provides a blockchain-enabled, high-availability transaction processing engine for real-time financial operations with automatic failover and framework recovery.

The key benefits of using CryptoBankPro include:

- CryptoBankPro provides a blockchain-enabled, high-availability
- transaction processing engine for real-time
- financial operations with automatic failover

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/CryptoBankPro.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
